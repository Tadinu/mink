# -----------------------------------
# POINT CLOUD -> GRASP POSE DETECTION
#
(C) GraspLoCoMo: https://github.com/Tadinu/grasplocomo/tree/dev to write out grasp pose as pos + quat format
NOTES
- Pre-provided clouds are not centered around Origin + So grasps outputted as global ones -> NOT ones relative to object point cloud
- The grasps are relative to object pointcloud, NOT the object mesh itself -> NOT VERY USEFUL

# -----------------------------------
# GRASP POSE GENERATION PROCEDURES --
#  
Note: <obj_type>: typename of object, eg: mj_mug, hammer, etc.
(1) Start with Obj mesh -> Use p3d to sample point cloud -> "grasplocomo/Clouds/<obj_type>_cloud.txt"
(2) Use GraspLoCoMo -> generate original grasps (as in global coord) -> "<obj_type>_grasp_results.txt"
./run_grasp_gen.sh <obj_type>

Use a sim framework like MuJoCo:
(3.1) Spawn obj composed of pointcloud as voxels from (1)
(3.2) Spawn gripper with original grasps generated from (2)

(4) Set GRASPS_FILE_PATH = GRASPS_ORIGINAL_FILEPATH
Log out local grasps of gripper (3.2) relative to object (3.1) -> "<obj_type>_grasp_results_recalculated.txt"

(5) Set GRASPS_FILE_PATH = GRASPS_RECALCULATED_FILEPATH
Use local grasps (5) in collision rollout checks in a cluttered scene, wherever the target to-be-grasped object is

(6) Publish through a ROS node
https://github.com/NVIDIA-ISAAC-ROS/isaac_manipulator/blob/main/isaac_manipulator_pick_and_place/scripts/grasp_reader.py

(7) Gripper open/close actions
https://github.com/ARISE-Initiative/robosuite/blob/master/robosuite/models/grippers/robotiq_85_gripper.py
https://github.com/ARISE-Initiative/robosuite/blob/master/robosuite/models/grippers/robotiq_140_gripper.py
