# Garmi Description (MJCF)

## Overview

This package contains a simplified robot description (MJCF) of the [Garmi Robot](https://geriatronics.mirmi.tum.de/en/garmi) developed by [TUM Munich Institute of Robotics and Machine Intelligence (MIRMI)](https://www.mirmi.tum.de/en). It is derived from the [publicly available
MJCF
description](https://github.com/tenfoldpaper/multipanda_ros2/tree/humble/garmi_packages/garmi_description/mujoco/garmi/assets).
